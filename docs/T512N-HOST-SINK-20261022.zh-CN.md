# T512N 主机＋外部 5V 受电适配

## 依据和边界

原机固件 `TCL/PB8_100A_FIH/PB8:13/TP1A.220624.014/512NCA05`，原厂
充电模块 SHA-256 为
`3335a81b95aad5154d820292949f0105e7f2f75fb3afaa2a4fbb7b594c398641`。
沿用已逆向核验的 REG0B=0x11、I2C6 0x6b 的本机分段电流编码，不使用
T551M 的 0x12 映射；OCV、JEITA、终止电流和电压表仍取本机原厂配置。

本轮从连接设备读取运行 DT，确认 `/soc/aon/usb@a00000` 为
`sprd,qogirn6lite-musb`，两个 extcon 均引用 phandle 0x6f；该 phandle 对应
`/soc/aon/spi@400000/pmic@0/typec@380`，Type-C 的实际 VBUS extcon 为 0x209。
由此接入公共 MUSB 路径，没有套用 41S 的 DWC3。此额外手动模式不是对原厂
Android 已支持相同接法的断言。

## 源码

T512N 自己的 `prepare-kernel.py` 在本机 charger、touch、display-clock 适配
完成后显式调用 `devices/common/musb-host-sink.py` 的 BQ 分支。该分支保留
BQ 的 REG08[2] Power Good 在线读取，不修改芯片电流控制。

普通主机继续按实际 HOST 接入开启本机升压；外部供电模式保持 CC 受电，
只在真实外部 VBUS、CC 和 BC1.2 检测完成时启用数据主机，并拒绝同时开启
本机升压。包含 T551M 实物确认的会话 PM 释放修正，退出主机时完成已有
会话检查，避免卡住下一轮自动/普通 OTG。

网页与屏幕复用已有能力检测；不允许将这个实验模式设为开机自动应用，
重启仍为自动策略。没有新增后台轮询、AT 调用或 NV 写入。

- 公共 MUSB 六项中的 BQ 适用五项通过，AW 专属一项明确跳过；检查了实际
  readiness、输入、升压边界、在线读数、重复准备不修改 BQ，以及 HCD 移除
  释放 PM 引用的正例/反例。根集线器生命周期和 BC1.2 重启回归也通过。
- 完整内核与配套模块编译通过，FGU、JEITA 与容器构建核验通过。
- 已保存当前 boot、模块与运行 DT。动态解析 Linux 槽位，部署保留原参数、
  initramfs 其他内容和诊断尾部；不以固定 A/B 位置代替槽位判断。

## 电脑供电短时对照

在实际电脑 5V 供电下连续读取十秒，每秒均为 host-sink/host、主机根集线器
存在、otg-vbus=disabled 和 Charging。保留 SDP 500 mA 输入预算，没有借此
改写充电电流或温控。FGU 报告正电流；本轮未校准电流传感器，不将其读数
视为 USB 电流表实测值或最大充电能力。

对照结束恢复 auto/device，NCM 重新连通，ModemManager 已发现基带对象，
未发现 Oops、BUG、panic 或未知符号。没有发送测试 AT 或改变上网卡设置。

## 三种模式实物通过

用户明确确认自动 OTG、手动主机及主机＋外部供电均正常。接回电脑读取的
同一轮日志交叉确认：

- 131.73 秒普通主机 external=0，执行 regulator enable；RTL8153/r8152
  成功枚举。141.56 秒退出，142.43 秒控制器完成运行时休眠。
- 148.79 秒外部供电主机 external=1，未开启本机升压；网卡再次枚举。
  155.73 秒充电管理报告 Charging，UNKNOWN 电源输入预算 1000 mA，
  T512N 专属电流映射回读充电设定为 977 mA。
- 157.74 秒退出受电主机，158.55 秒完成休眠；167.21 秒重新进入普通主机，
  升压开启、网卡枚举成功，没有旧会话阻断普通 OTG 的回归。
- 178.24 秒退出，179.04 秒完成休眠。最终回到 auto/device、NCM，
  原电脑 SDP 500 mA 预算恢复，未发现 Oops、BUG、panic 或未知符号。

FGU 报告电流与充电寄存器设定存在差异，本次不把 FGU 数字当作 USB 输入
电流实测，也未通过修改校准消除该差异。用户的充电/网口结论与驱动角色、
充电状态、枚举及退出时序互相吻合。

本轮验证限于该 T512N 与所测扩展坞/网卡组合的三种模式切换，不扩大为长期
负载或其他外设验证。原始回执保存在忽略目录 `three-modes-confirmed.txt`。
