# 自动网络模式编号设置

网页“蜂窝 → 适配设置”新增“自动网络模式编号”：默认、134、152。
默认选项显示实际数字；说明指出双卡时延迟很高或明显卡顿可尝试调整，
效果依赖本机基带，不将 152 宣称为通用低延迟模式。

| 机型 | 默认 |
| --- | --- |
| T551M | 152 |
| E5、M8、T512N | 134 |

`unisoc_modem.main.auto_work_mode_default` 由公共构建/更新适配入口按机型
生成；`auto_work_mode` 为用户选择（default/134/152）。原有显式设置保留。
网页先读取配置再渲染，保证显示的默认数字与后端一致。

保存配置不额外发送 AT 或重置射频。用户需要在网络锁定重新应用自动模式；
保存了自动模式且启用了开机回放的 SIM，下次启动会使用新编号。
4G、SA、NSA 等显式模式不变；屏幕沿用公共锁定后端，因此自动模式同步生效。
仍使用现有 AT 所有者、分卡寻址、回放顺序及重连流程。

作用域覆盖 E5、T551M、M8、T512N；E5 仓库没有改变 SIM2 默认射频策略。

离线验证：实际 LuCI 视图的默认值/覆盖值及三语言渲染、锁定设置与第二槽位
保留、启动配置按机型生成及更新保留用户选择。本次尚未部署或重打包。
