# 基带偏好设置公共链路核对

## 来源与范围

对照本机 `D:/Git/ufi_tools_uni_app` 的独立版
`StandaloneNetworkController.kt`，`setBasebandPrefer(true)` 顺序发送
`AT+CEUS=1`、`AT+CEMODE=2`。本文沿用该功能名称和指定数值，不将名称
当作其射频性能或标准语义已经验证的证据。

## E5 公共实现

- 已内置 `/opt/e5/e5-data-priority`，无需新增另一套开机回放。
- ModemManager 的初始化结束、射频启用成功回调均调度同一异步任务。
  基带恢复进入上述生命周期时重新应用，没有持久化完成标记跳过。
- 适用于 E5、T551M、M8、T512N、远航 41S、K1 的公共装配入口。
- 按所选上网卡通过现有 AT owner 依序发送两条指令，不打开新 tty，
  不发送射频重启命令，不阻塞拨号，不覆盖用户关闭射频的策略。
- 每条初次发送加最多三次重试，以最终 OK 确认；耗尽会记录失败，不能
  将任务已调度表述成设置已经成功或永久保持。无额外轮询。
