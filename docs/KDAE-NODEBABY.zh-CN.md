# E5 内置存储固件：KDAE 与节点小宝

目标是内置 eMMC 的独立 e5root 分区，基于 kanoqwq/e5-linux 697cc0b（2026-10-14，已合入安装识别、VoLTE/VoNR 与锁屏唤醒修正），包括作者最新存储 DMA、温控、双卡短信/移动性和内置离线更新修复。构建包含 Go KDAE v2.2.5（92aa565，最新引擎 eb510872 / 控制器 b089b568，保留 DNS 与热重载修复）及官方 ARM64 节点小宝 4.3.5-734。

LuCI → 服务 → daed / 节点小宝 自动打开当前设备管理界面。首次使用自行创建 KDAE 账号、导入订阅并绑定节点小宝。固件不含任何用户订阅、节点、密码、数据库、JWT、SSH 私钥或组网身份；本机固件/NV 从接收设备自身提取。

已有内置分区使用电脑安装器的更新入口（update-openwrt），核对模型、e5root 标记与容量、镜像/boot 哈希后，进入 initramfs 离线更新现有分区。更新不重新缩容 userdata、不改变 GPT、不创建 TF 或额外 OTA 分区。不要对已安装设备调用首次安装/重建分区入口。

内置更新将本机 KDAE/节点小宝的写入进程短暂暂停，统一归档数据库及 WAL、绑定数据，然后无论成功/失败都恢复进程。归档排除节点小宝公开软件文件，防止旧程序覆盖新版。随后使用作者现有的离线更新、容量与回读检查；这些本机数据只在该设备自己的更新暂存目录，不进入公开固件。

KDAE 新安装默认 /etc/daed-kdae；存在早期 E5 /etc/daed/wing.db 时继续使用原 Go 数据。Rust daed.db 不会被自动读取。模块在 Linux 大小写敏感文件系统构建与归档，保留完整模块及内嵌配置检查。

本次只编译与离线验证，不自动刷写设备。作者的 TF 安装功能仅是上游包的其他入口，不是本用户设备的安装路线。
