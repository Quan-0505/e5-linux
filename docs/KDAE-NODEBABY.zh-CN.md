# E5 OpenWrt：Go KDAE 与节点小宝

Actions → Build and publish OpenWrt 使用本 fork 的 E5 固定子模块、E5 6.18 内核和 OpenWrt 25.12.5，构建并校验完整通用 ZIP/TAR 刷入包。
MU300 clean-tf-7.2 只作为构建校验参考，不使用它的 boot、设备树或模组适配。

LuCI → 服务 → daed / 节点小宝 自动打开当前设备的 2023 / 9118 管理界面。Go KDAE 从固定源码提交重新编译，带现代管理界面与 DNS 重载修复；节点小宝使用官方公开 ARM64 4.3.5-734，并校验 SHA256。

初次使用请自行创建 KDAE 账号、添加订阅，并为节点小宝绑定自己的设备。镜像不带账号、数据库、JWT、订阅、节点、SSH 密钥或节点小宝身份。KDAE 数据保存 /etc/daed-kdae；不读取旧 Rust 数据库。服务等待网络的工作由 procd 子进程执行，不阻塞启动确认。

内核显式启用 NETKIT、VETH、BPF/JIT/BTF、流量分类和入口 qdisc；最终内核配置与 ELF、文件清单在发布前校验。数据源自动更新沿用 KDAE 的服务实现。

更新器保留设备本地 KDAE 数据库与节点小宝身份，不用旧软件覆盖新软件；SQLite 使用在线备份读取已提交 WAL。旧系统更新前需有 python3-sqlite3；缺少时更新在切换镜像前失败，原镜像保留。通用发布包始终没有这些设备状态。

固定的信息屏 09b7ec8 的 USB 调度器有未知操作先查询硬件导致错误返回不一致的问题。tools/prepare-screen-compat.py 校验原始 SHA 后加入参数拒绝，保留原 USB 测试并记录补丁在本仓库。

节点小宝默认仅提供本机服务与自行授权的隧道路由，不预置个人异地网段或放开隧道防火墙。需要下游转发时按自己的网段配置防火墙和回程。

仅编译不代表硬件实测通过；刷入使用 E5 原有安装器，校准与 vendor 数据从接收设备自身提取。不要使用 MU300 固件或其他设备的身份备份。
