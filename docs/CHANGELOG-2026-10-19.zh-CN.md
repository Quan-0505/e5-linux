# 2026-10-19 更新日志：E5 / T551M / M8 / T512N

本页包含本批固件累计的 Wi-Fi 调整，以及本次提交的 CPU 控制、蜂窝设置和安装器公共代码。机型默认值、固件选择和硬件差异继续按设备区分。

## Wi-Fi 稳定性与兼容性

- 公共热点配置关闭 U-APSD，兼容新装和升级保留的旧配置；保留 WMM、信道、带宽、密码及其他省电配置，不新增常驻轮询。
- 修复无线事件解析的长度与边界检查，避免异常或截短事件触发越界；相关修复接入公共构建入口。
- 对齐原厂 Marlin3Lite 拼接固件的选段行为：按本机 eFuse 选择对应固件变体，避免文件相同却实际运行了不同变体。核验范围内的普通单镜像及其他芯片保持原流程，读取失败不猜测选段。
- 上述改动不能等同于所有高延迟和掉线均已解决。U-APSD 在 U30 Air 曾出现软件配置为关闭、固件广播仍宣告开启的情况，E5 系列也不能仅凭配置推断固件行为。
- 本仓库四款机型使用 SDIO，不照搬 MU300 的 PCIe RX 队列修复或 CPU0 禁用休眠策略；本次没有修改它们的 CPU0 idle 策略。

原厂证据及验证边界：[T512N 固件选择与延迟分析](T512N-WIFI-LATENCY-20261019.zh-CN.md)、[公共 U-APSD 策略](WIFI-UAPSD-POLICY-20261019.zh-CN.md)。

## CPU 核心控制

- 网页 CPU 设置新增逐核心开关，可按需控制可操作核心，并勾选开机自动应用。CPU0 保持在线，默认不会主动关闭其他核心。
- 修复网页请求携带会话字段时误报「CPU 核心配置无效」的问题，继续拒绝非法参数和关闭 CPU0 的请求。
- 核心开关与调频操作互斥，失败时尝试回滚。关闭整个 CPU 簇后，保留该簇原有的频率配置，避免保存其他设置时将其覆盖。
- 公共内核明确启用 CPU 热插拔，并增加构建能力检查；旧内核缺少支持时需配套更新内核和模块。

## 蜂窝网络设置

- 「自动模式兼容性」移至「蜂窝 → 网络锁定 → 网络模式」，仅在自动模式下显示，避免入口藏在适配设置中。
- 提供「机型默认」「全制式自动（134，含 2G）」「自动选网（152，不含 2G）」，补齐中文、英文、土耳其语名称及说明。
- T551M 默认 152；E5、M8、T512N 默认 134，保留用户明确选择。E5 仓库不改变 SIM2 默认射频策略。
- 说明双卡高延迟、卡顿及自动驻网偏好的用途，不将编号当作固定频段优先级或承诺一定驻留 n78。应用沿用现有 AT 所有者、回放顺序和重连流程。

## 安装器公共代码

- 同步共用的通知事件、界面提示和打包辅助文件，避免两个仓库后续同步时遗漏依赖。
