该包已更新到用户通过 USB 连接的 E5 既有内置 e5root 安装。更新程序验证了目标机型、现有分区标识、空间和包哈希；离线更新只写入系统启动槽对应载荷。更新前已建立并校验本地恢复备份。更新前后主/备 GPT 对比一致，未格式化 userdata、未重新缩容、未写入 TF。

升级后确认运行版本、内核与 e5root 布局匹配；Rust daemon 的文件哈希、版本和服务脚本与候选包一致。数据库校验、Rust 配置校验和 DaedNext 页面校验通过。旧 Go 数据库的用户、配置、DNS、路由记录均保留；有效群组策略、订阅关联与定时任务保留。订阅首次刷新成功，节点数量按上游刷新结果变化。节点小宝服务和 TCP DNS 查询通过。

网络探测在当时的设备路由环境下有部分差异：若干 HTTPS 目标和 UDP DNS 查询超时；其他 HTTPS 探测与 TCP DNS 查询成功。超时可能与目标站点及具体路由有关，本次记录不宣称所有外部站点、UDP 中继或不同网络环境均可达。用户自己的订阅、节点、密码、数据库、设备身份和备份均未进入源码、工作流附件或 Release。

本包面向已经安装在 E5 内置 e5root 的用户，通过安装器选择“更新 OpenWrt”进行保数据升级。不要选择首次安装、重新分区、缩容或 TF 安装入口。新设备安装或其他设备型号需要各自独立核验。
