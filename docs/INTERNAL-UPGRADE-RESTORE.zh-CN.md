# 恢复既有内置 e5root 的升级链

PR #7 已修复原生 x86 软件包构建，完整构建 38924909684 成功。该产物的启动镜像尚无内置 e5root 支持，不能作为现有内置安装的升级包。

此补丁从已验证的 codex/e5-internal-kdae 分支恢复内置根分区识别、试启动标记、离线 initramfs 更新和保留配置归档。继续使用主分支现有的设备子模块及屏幕、Wi-Fi、蜂窝改动；启动镜像里的 e5-gpt 读取当前固定的公共设备子模块。

安装包补齐 flash.py --update 已经引用却没有打包的 SSH 更新工具、设备端暂存工具、软件排除清单和状态快照工具。更新先上传并校验，再离线写既有根分区；保留账号、订阅数据库及 WAL、节点小宝本机身份、配置和目标自身固件。公共软件文件不从旧系统覆盖新版本，Go KDAE 固定为 v2.2.6-kdae。

不执行 TF 安装、重新缩容、改 GPT 或格式化 userdata。首次内置安装流程不作为本补丁的实机验收目标。

验证包括分区发现 5 项、离线更新 15 项、安装保护 7 项、发布校验 21 项，以及真实 SQLite WAL 写入进程的快照/恢复与异常退出后恢复运行。CI 新增更新链清单校验，缺少上传工具、更新脚本或软件排除清单时拒绝产物。完整固件构建和实机升级仍需分别通过，测试结果不能替代实机验收。
