# 远航 41S 全新安装无触控、亮灭屏同步失败

## 已确认原因

2026-10-22，连接的 `yuanhang41s / P720S11` 全新安装后，运行
`6.18.54-yuanhang41s-bringup1`。ST7123 模块存在，本机触控固件也已安装，
但 `/proc/bus/input/devices` 没有触控设备。

启动日志在 4.147 秒记录：

```text
Direct firmware load for sitronix/st7123.bin failed with error -2
own touch firmware unavailable
probe with driver sitronix-st7123 failed with error -2
```

驱动在 initramfs 中同步下载 RAM 固件；公共启动脚本原先直到装载
`wcn_bsp.ko` 才从本机系统导入固件。41S 的触控早于 WCN，当前启动列表甚至
没有早期 WCN，导致探测失败后不再自动绑定。正式根目录有固件也无法补救
已经结束的探测。之前带本机固件的 RAM 探测能工作，不代表通用安装包能工作。

亮灭屏服务要求真实触控设备存在，以确保息屏关闭触控、亮屏恢复触控；
因此同一缺失还导致“屏幕状态同步失败”。不是取消检查就能修复。

## 修复

`boot/init` 在装载 `st7123.ko` 之前调用现有本机固件导入流程，保留
WCN 原来的入口。复用既有独立分区、TF、userdata 固件发现逻辑、只读挂载及
优先级，不新增重试常驻服务，不嵌入参考机固件，不修改触控协议、基带顺序。
没有 ST7123 的机型保持原有触发点。

本机原厂参考：Android 13 `20240508.225723`、内核
`5.4.254-android12-9-gd0931382de8e`，详见机型 README；使用本次安装已提取的
`sitronix_firmware_huaying.dump`，SHA-256：
`d60621216339c0caa2f850a154b5631eb2022026c0dfb6096e7274542224e084`。

## 验证及边界

- 实机先重新绑定同一驱动，RAM 下载成功、触控输入设备注册，屏幕同步命令通过。
- 永久修正本机 OpenWrt boot 的 init；保留原内核、命令行、槽位元数据、诊断区。
  Android B 槽完整 SHA-256 前后相同；未改 Android、NV 或用户配置。
- 重启后无需手动绑定：4.353 秒导入本机独立分区固件，4.502 秒触控就绪，
  输入设备为 `Sitronix ST7123`、720×1600，模块加载失败数为 0。
- 实机执行三次息屏/亮屏控制，触控 `inhibited` 分别为 1/0，均成功；新启动
  未出现缺固件或屏幕状态同步错误。实际手指触摸体验仍需用户观察。
- 9 项固件发现/启动顺序离线测试覆盖无早期 WCN、传统 WCN、无相关模块、
  独立分区触控固件链接导入无等待，以及 TF/userdata 原有优先级。

实机备份、哈希、修复脚本和验证输出位于忽略目录
`work/yuanhang41s-touch-20261022/`。旧发布包不会因源码修改自动修正，
应使用本次重新生成的远航 41S 安装包。
