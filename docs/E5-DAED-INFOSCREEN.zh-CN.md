# E5 信息屏 DAED 适配

E5 的小屏保留原生信息屏界面，不嵌入完整 DAED 管理站。预装的 DAED 信息屏应用提供常用操作：查看 DAED 运行状态、启动、停止、重载和更新订阅。需要登录 DAED 时，屏幕显示一次性二维码；手机连接 E5 Wi-Fi 后扫码，在手机页面填写 DAED 账号密码。设备只保存受权限保护的登录令牌，不保存明文密码；令牌有效期遵循 DAED 的 30 天会话期限。

在信息屏首页或其他信息屏应用中按实体数字 `0`，会直接打开 DAED 应用。当前快捷键固定映射，没有在屏幕 UI 中自定义按键的设置项。应用已打开时不会重复刷新；DAED 应用未安装时屏幕提示用户。主程序先处理按键锁和息屏状态，因此数字 `0` 不会解锁或唤醒息屏设备；电话通话进行中也不会抢占实体按键。

DAED 插件、二维码配对后端和升级保留逻辑位于本仓库 `openwrt/infoscreen-plugins/daed/` 与固件安装代码中。信息屏核心固定为 `ci/infoscreen` 的 gitlink 版本。构建 OpenWrt 根文件系统时，`tools/patch-e5-daed-shortcut.py` 将数字 `0` 快捷入口应用到暂存的核心 `app.js`，不需要维护第三方信息屏 fork。若上游核心调整按键处理代码，补丁会因锚点不匹配而让构建失败，要求先适配并验证再更新上游锁定版本。

回归检查 `python3 tools/tests/infoscreen-daed-key0.py` 从固定 gitlink 的原始文件开始，验证补丁唯一应用、JavaScript 语法、息屏/按键锁保护顺序和重复应用行为。`python3 tools/tests/infoscreen-daed-app.py` 检查 DAED 屏幕控制与配对后端；完整发布工作流另运行信息屏浏览器和设备侧检查。实机确认还需核对屏幕按键、扫码登录、服务状态和订阅操作。

固件不包含个人订阅、节点、DAED 账号密码、配对令牌、数据库、设备身份或 NV 数据。
